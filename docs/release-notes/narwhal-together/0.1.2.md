# NARwhal Together 0.1.2

Hardening release for Minecraft 1.21.11 and 1.21.1 on Fabric.

## Updates

- Keeps the controller-friendly next-player teleport shortcut behavior from the 0.1.x releases.
- Refactors shared client controller integration and version-specific Minecraft adapters for clearer maintenance.
- Publishes from the hardened multi-version CI and release workflow with per-target artifacts.
- Updates packaged metadata to point at the renamed `minecraft-mods` repository.

## Requirements

- Minecraft Java Edition 1.21.11 or 1.21.1
- Fabric Loader
- Fabric API
