# NARwhal Together 0.1.3

The two Minecraft versions now share the same teleport logic and controls. Press G to visit the next player, or bind the action in Controlify.

Use the build for Minecraft Java Edition 1.21.11 or 1.21.1 with Fabric Loader and Fabric API. Controlify is optional. The 1.21.1 jar now declares the Fabric Loader 0.16.14 minimum it is built against.
