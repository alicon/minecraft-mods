# Cops and Robbers 0.1.2

Smoke-tested hardening release for Minecraft 1.21.11 on Fabric.

## Updates

- Refactors police cruiser, robber, bank, jail, capture, patrol, and client-control code into smaller maintenance-focused helpers.
- Keeps the 0.1.x police cruiser, fire truck, bank, police station, robber, and jail gameplay behavior intact.
- Adds repository quality gates that protect mod metadata, versioned sources, release notes, formatting, public APIs, and client/server source boundaries.
- Publishes from the hardened CI and release workflow with corrected versioned artifact paths.

## Requirements

- Minecraft Java Edition 1.21.11
- Fabric Loader
- Fabric API
