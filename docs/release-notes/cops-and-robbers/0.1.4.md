# Cops and Robbers 0.1.4

The whole crew got new uniforms, and the cruiser and fire truck finally look like two different rides. The bank, police station, fire station, and all nine inventory icons got a makeover too.

- Drive straight through the new station garage doors.
- Robbers go after vault gold and leave ordinary chests alone.
- Solid walls now stop the fire truck's water cannon.

For Minecraft Java Edition 1.21.11 with Fabric Loader and Fabric API.
