# Playtest Bridge 0.1.0

- Added a loopback-only HTTP bridge for local Minecraft mod playtesting.
- Added endpoints for health, state snapshots, chat broadcast, command execution, player ability control, entity interaction, entity cleanup, block placement, and screenshot capture in local test worlds.
- Expanded state snapshots with player creative/flying abilities plus entity no-gravity, water, and item-stack details for behavior assertions.
- Added Modrinth disposable-world automation and Mushroom Yorkie live scenarios covering taming, owner commands, harness/lead behavior, exact food/toy effects, dog bowl care, same-day bowl refill rejection, outdoor relief, nighttime sleep, water fetch, survival cliff refusal, water sit safety, creative wet recovery, creative flying follow, cleanup, and screenshots.
