# Playtest Bridge 0.1.0

- Added a loopback-only HTTP bridge for local Minecraft mod playtesting.
- Added endpoints for health, state snapshots, chat broadcast, command execution, player ability control, entity interaction, entity cleanup, block placement, and screenshot capture in local test worlds.
- Expanded state snapshots with player creative/flying abilities plus entity no-gravity, water, and item-stack details for behavior assertions.
- Added Modrinth disposable-world automation and Mushroom Yorkie live scenarios covering taming, owner commands, harness/lead behavior, exact food/toy effects, dog bowl care, same-day bowl refill rejection, outdoor relief, nighttime sleep, water fetch, survival cliff refusal, water sit safety, creative wet recovery, creative flying follow, cleanup, and screenshots.
- Adds read-only native crafting resolution with exact outputs and matching recipe IDs, plus bounded grid validation.
- Adds bounded native walking/boat input with start/status/cancel, exact copied-save/player/boat identity checks, neutral release and tick/position receipts for live travel tests.
- Reports frozen-world state and exact Overworld game time separately from the server counter.
- Adds native air, fall-distance, hurt-timer and recent damage-type observations to nearby living-entity snapshots.
- Adds explicit native dead-owner respawn for guarded disposable worlds, separate recovery receipts and a matrix preflight that refuses dead owners before setup. Failure screenshots retain the death screen.
- Adds explicit guarded native owner respawn with separate recovery proof, dead-owner matrix preflight and death-screen-preserving failure capture.
- Adds bounded native jump input with owned native launch and in-window server-accepted rise evidence and read-only player pose, collision and precise-position observations.
