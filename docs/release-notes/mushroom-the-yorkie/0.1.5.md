# Mushroom the Yorkie 0.1.5

This one's a cleanup under the hood. The two Minecraft versions now share the same Yorkie behavior and the same dog and squirrel models. Mushroom still does his usual rounds of treats, naps and squirrel trouble.

Use the build for Minecraft Java Edition 1.21.11 or 1.21.1 with Fabric Loader and Fabric API. Update the server or LAN host and all participating clients together.
