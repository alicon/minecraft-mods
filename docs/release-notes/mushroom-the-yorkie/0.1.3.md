# Mushroom the Yorkie 0.1.3

A companion behavior update for Minecraft 1.21.11 and 1.21.1 on Fabric.

## New companions and comforts

- Adds woodland squirrels with their own spawn egg, natural spawning, tree seeking and climbing. Mushroom can chase them and return to his owner afterward.
- Adds a doghouse for sheltered rest alongside the existing dog bed.

## Behavior fixes

- Improves squirrel routes around branches and blocked tree faces, including recovery when a climbing surface changes. Hits release climbing control so normal knockback, gravity and landing damage work properly.
- Preserves fetched toys through interrupted fetches, inventory or game-mode changes, and saved-world reloads. Improves creative flying fetches and returns after the owner lands.
- Keeps wet or airborne Mushroom from curling up to sleep before reaching safe support. Improves bed approaches and doghouse rest, and lets a starving sleeper wake for an available meal.
- Keeps bathroom trips active through doorways and prevents nighttime recovery from starting an unrelated outside request.
- Preserves sit orders on dry floating boats, releases rest in actual water hazards, and improves escape from submerged boat obstructions.
- Prevents immediate unwanted reboarding after owner help and clears stale steering when an owner dismounts or takes off.

## Requirements

- Minecraft Java Edition 1.21.11 or 1.21.1
- Fabric Loader and Fabric API
- Install on participating clients and the server or LAN host.

This remains an alpha release.
