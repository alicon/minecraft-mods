# Mushroom the Yorkie 0.1.2

Smoke-tested hardening release for Minecraft 1.21.11 and 1.21.1 on Fabric.

## Updates

- Refactors Mushroom's entity, interaction, fetch, scent, care, persistence, sound, and version-adapter code into smaller maintenance-focused helpers.
- Keeps the 0.1.x companion behavior intact, including sitting, fetching, outdoor relief, creative flight support, food/bowl care, and lost-dog recovery.
- Fixes a live domestic-care edge case where a filled dog food or water bowl could apply its need effects twice after being converted back to an empty bowl.
- Fixes fetch edge cases found by live playtesting: returned toys no longer apply play rewards twice, reachable toys are not abandoned after a brief navigation pause, and shallow-water toys can be retrieved from a safe edge.
- Adds and enforces broader JVM tests and repository quality gates for future Mushroom changes.
- Publishes from the hardened multi-version CI and release workflow with per-target artifacts.

## Requirements

- Minecraft Java Edition 1.21.11 or 1.21.1
- Fabric Loader
- Fabric API
